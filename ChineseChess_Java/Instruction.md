# 中国象棋 (Chinese Chess) 游玩说明

欢迎体验这款基于 Java 开发的中国象棋游戏！本文档将指导您如何开始游戏、进行操作以及使用各项功能。

## 1. 账户与登录
游戏启动后，您需要登录账户才能保存游戏进度和历史记录。
*   **注册**：如果您是第一次游玩，请点击 "Register" 按钮，输入用户名和密码进行注册。
*   **登录**：输入已注册的用户名和密码，点击 "Login" 进入主菜单。
*   **数据保存**：您的对战历史和账户信息将保存在本地的 `accounts/` 目录下。

## 2. 主菜单
登录成功后，您将看到主菜单，包含以下选项：
*   **P2P (人人对战)**：两位玩家在同一台电脑上轮流操作，进行红黑对抗。
*   **AI (人机对战)**：挑战内置的智能 AI，测试您的棋力。
*   **Settings (设置)**：调整游戏设置（如背景音乐）。
*   **Help (帮助)**：查看简要帮助信息。
*   **About (关于)**：查看开发者信息。
*   **Quit (退出)**：退出游戏。

## 3. 游戏界面与操作
进入游戏后，界面主要分为棋盘区、侧边栏和功能按钮区。

### 3.1 走棋操作
1.  **选中棋子**：鼠标左键点击己方棋子（红方或黑方）。
    *   **蓝色框**：表示当前选中的棋子。
    *   **红色框**：显示该棋子所有合法的移动位置（提示功能）。
2.  **移动/吃子**：点击任意一个带有**红色框**的位置，棋子将移动到该位置。
    *   如果目标位置有敌方棋子，将触发吃子动画，敌方棋子会被移至棋盘右侧的“观战区”。
3.  **取消选中**：点击棋盘空白处或非合法移动位置，可取消当前选中状态。

### 3.2 界面元素
*   **倒计时**：右上角显示当前走棋方的剩余思考时间。超时可能会导致判负（视具体规则而定）。
*   **当前方提示**：右侧中部会显示当前轮到哪一方走棋（Red/Black 图标）。
*   **观战区**：右侧下方区域展示了双方被吃掉的棋子。

## 4. 功能按钮
游戏过程中，您可以使用右侧的按钮进行辅助操作：

*   **Undo (悔棋)**：
    *   点击后可撤销上一步操作，恢复到上一步的棋盘状态。
    *   **注意**：为了公平起见，**每步棋只能悔棋一次**。如果您已经悔棋过，必须等下一步棋走完后才能再次使用。
*   **Surrender (认输/重开)**：
    *   点击后弹出确认框，确认认输将结束当前对局，并可选择重新开始或返回菜单。
*   **Music (音乐)**：
    *   控制背景音乐的播放与暂停。
*   **Back (返回)**：
    *   退出当前对局，返回主菜单。

## 5. 游戏规则简介
本游戏遵循标准的中国象棋规则：
*   **红先黑后**：红方先行。
*   **胜利条件**：吃掉对方的“帅/将”，或使对方无棋可走（困毙）。
*   **特殊规则**：
    *   **将帅不见面**：红帅与黑将不能在同一条直线上直接面对面，中间必须有棋子隔开。
    *   **长将/长捉**：禁止长将或长捉（部分检测逻辑已内置）。

## 6. 常见问题
*   **Q: 为什么我不能悔棋？**
    *   A: 可能是您刚刚已经悔棋过了，或者当前还没有进行任何走棋。
*   **Q: 游戏进度会保存吗？**
    *   A: 是的，正常退出游戏或返回菜单时，系统会自动保存当前对局的历史记录到您的账户文件中。
